Микросервисное API для корпоративного ИИ-ассистента на базе архитектуры **RAG (Retrieval-Augmented Generation)**.
Проект позволяет загружать внутренние регламенты компании, автоматически векторизовать их и задавать вопросы нейросети. ИИ отвечает **строго на основе корпоративной базы знаний**, исключая вероятность "галлюцинаций".

## ✨ Ключевые особенности и Архитектура

- **Векторный поиск (Vector Search):** Использование расширения `pgvector` для PostgreSQL для семантического поиска по документам.
- **Локальные модели ИИ:** Интеграция с локальной нейросетью через `Ollama` (используется модель `bge-m3` для генерации эмбеддингов).
- **Асинхронная обработка (Jobs/Workers):** Тяжелые задачи по векторизации текста выполняются в фоне через Redis-очереди, не блокируя ответ API.
- **Строгая валидация (Spatie Data):** Использование DTO (Data Transfer Objects) для валидации входящих данных и формирования типизированных ответов.
- **Стандартизация ошибок:** Все ошибки API (включая Validation и Auth) строго соответствуют международному стандарту **RFC 7807 (Problem Details for HTTP APIs)**.
- **TDD & Pest:** Покрытие бизнес-логики изолированными Feature-тестами с использованием мокирования сервисов ИИ и `Queue::fake()`.

## 📦 Инфраструктура (Docker)

Проект работает по принципу "Plug and Play". В `docker-compose.yml` настроены:

- **Nginx & PHP-FPM**
- **PostgreSQL + pgvector** (База данных и векторное хранилище)
- **Redis + RedisInsight** (Брокер очередей и кэш)
- **PHP Worker** (Демон для фоновой обработки задач)
- **Ollama** (Локальный сервер для моделей машинного обучения)

## 🚀 Быстрый старт (Установка)

Для удобства управления контейнерами используется `Makefile`.

1. **Клонируйте репозиторий и настройте окружение:**

    ```bash
    cp .env.example .env
    ```

2. **Поднимите Docker-контейнеры:**

    ```bash
    make up
    ```

3. **Установите зависимости и подготовьте БД:**

    ```bash
    make composer c="install"
    make art c="key:generate"
    make art c="migrate"
    ```

4. **Загрузите модель ИИ для векторизации:**
   _(Контейнер Ollama скачает модель `bge-m3` для создания векторных представлений)_
    ```bash
    docker compose exec ollama ollama pull bge-m3
    ```

## 📖 Примеры использования API

Для удобства вся документация доступна в Swagger. Сгенерировать её можно командой: `make swagger`.

### 1. Загрузка документа в базу знаний (Ingest)

**POST** `/api/v1/documents/ingest`
Текст разбивается на смысловые фрагменты (чанки) и отправляется в фоновую очередь для векторизации.

**Запрос:**

```json
{
    "title": "Корпоративный регламент компании TechNova",
    "content": "## 1. Отпуска и больничные\nКаждый сотрудник имеет право на 28 календарных дней оплачиваемого отпуска в год. Отпуск можно дробить, но одна из частей должна быть не менее 14 дней. Заявление на отпуск подается в HR-отдел минимум за 2 недели до начала.\n\nБольничный лист оплачивается в размере 100% от среднего заработка, если непрерывный стаж работы сотрудника превышает 8 лет. Если стаж от 5 до 8 лет — оплачивается 80%. При стаже менее 5 лет — 60%. Для оформления больничного необходимо предоставить электронный номер (ЭЛН) в HR-отдел в течение 3 дней после закрытия больничного листа.\n\n## 2. Обеспечение техникой\nПри приеме на работу сотруднику выдается рабочий ноутбук (MacBook Air или аналог на Windows). Замена техники производится планово раз в 3 года. В случае поломки техники по вине сотрудника, ремонт оплачивается в пропорции 50/50 (компания/сотрудник).\n\nСотрудники на удаленке имеют право на компенсацию расходов на интернет в размере 1500 рублей в месяц. Для получения компенсации нужно загрузить чек об оплате во внутренний портал до 5 числа следующего месяца.\n\n## 3. График работы\nСтандартный график работы — с 10:00 до 19:00 по московскому времени. Обеденный перерыв длится 1 час и может быть использован в любое время с 13:00 до 15:00. Возможен гибридный формат работы (3 дня в офисе, 2 дня дома) по согласованию с непосредственным руководителем."
}
```

**Ответ (200 OK):**

```json
{
    "message": "Документ успешно разбит на части и добавлен в очередь на векторизацию.",
    "processedCount": 3
}
```

### 2. Чат с ИИ-ассистентом (RAG Search)

**POST** `/api/v1/chat`
Система превращает вопрос в вектор, находит релевантные куски текста в БД и просит LLM сформировать ответ. Возвращает ответ и `sourceIds` (ID исходных документов).

**Пример A (Анализ данных):**

```json
// Request
{
  "question": "Я пролил кофе на рабочий макбук по своей вине. Кто будет оплачивать ремонт?"
}

// Response
{
  "answer": "Ремонт будет оплачиваться в пропорции 50/50: компания и вы как сотрудник.",
  "sourceIds": [3, 4, 2]
}
```

**Пример B (Сложная логика):**

```json
// Request
{
  "question": "Я хочу разбить отпуск: взять сначала 7 дней, потом еще 7, и потом 14. Могу ли я так сделать и за сколько дней нужно писать заявление?"
}

// Response
{
  "answer": "Да, вы можете разбить отпуск на несколько частей. Согласно документу #1, одна из частей должна быть не менее 14 дней, что в вашем случае выполнено. Для оформления отпуска необходимо подать заявление в HR-отдел минимум за 2 недели до начала.",
  "sourceIds": [1, 2, 5]
}
```

**Пример C (Защита от галлюцинаций):**
Если в базе нет информации, ИИ не придумывает ответ, а честно об этом сообщает.

```json
// Request
{
  "question": "Оплачивается ли в компании ДМС (медицинская страховка)?"
}

// Response
{
  "answer": "Я не знаю ответа на этот вопрос на основе предоставленной базы знаний.",
  "sourceIds": [2, 3, 4]
}
```

## 🧪 Тестирование

Проект покрыт тестами фреймворка **Pest**. Обращения к API нейросетей замоканы, чтобы тесты выполнялись быстро и не зависели от внешних сервисов.

Запуск тестов:

```bash
make art c="test"
```
